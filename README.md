## Preview locally

The site is a static HTML/CSS/JavaScript project. Open `index.html` in a browser to review the portfolio locally. GitHub Pages publishes the site from this repository.

## Repository structure

- `index.html` — portfolio content, styling, and project cards
- `assets/projects/` — local portfolio images, including the e-commerce revenue chart

Project thumbnails link to screenshots or charts in the matching project repository, except for the e-commerce revenue chart stored here. Keep those image links and project repository links aligned when updating a project.
